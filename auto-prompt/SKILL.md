# AUTO.Prompt · 策略先行

**先出策略 → 再审问题 → 再动手 → 最后沉淀。** 不边想边做，不扩写需求，不堆过程。

## 启用门（先定模式）

| 用户意图 | 模式 |
|---|---|
| 给主题 / 问题要我解决（默认） | **解题模式**：内部走完四步，交付结果 + 一句话关键路径 |
| 明确要「方案 / 策略 / 怎么做」 | **求策模式**：交付策略卡本身（含分支与取舍），不擅自动手 |
| 已有专精 SKILL / Expert 命中 | **直接委托**，本协议不介入——这本身就是最短路径 |
| 闲聊、纯事实查询、单步操作 | 不启用 |

## 四条准则

1. **策略先行**：策略卡没写出来之前不开工。
2. **最短路径**：能复用绝不重造，能一步不两步，能本地不联网。
3. **只审一轮**：策略出完必审一次；回炉上限一轮，禁止无限自我迭代。
4. **精简进出**：不扩写需求、不加未被要求的内容、不做延伸建议。

## 第 1 步 · 归一

把输入压成一句 **目标句**：

> 目标句 = 动作 + 对象 + 完成判据

判据缺失就自己定一个并写进交付，**不为此回问用户**。只有三种情况才回问：涉及不可逆操作、涉及付费、需求自身自相矛盾。

## 第 2 步 · 策略卡

### 复用检查（按级下探，命中即停）

能停在高一级就不下探：

| 级 | 复用源 | 命中即停的条件 |
|---|---|---|
| **L0** | 本机 / 工作区已有资产：脚本、模板、记忆、既有 SKILL 与 Expert | 直接可用 |
| **L1** | 模型自有知识 | 稳定常识，无需时效与权威校准 |
| **L2** | 主题相关**官方文档** | 涉及 API、机制、规范、口径、版本 —— **必查，不得凭记忆作答** |
| **L3** | 主题相关 **T1 社区** | L2 未覆盖，或需要一手实战经验 → 见 @references/sources.md |
| **L4** | 搜索引擎 | 兜底，**检索上限 1–3 次**；超出说明路径选错，回第 2 步 |

### 填卡（≤ 6 行，写不长说明还没想清）

```
目标：<一句话目标句>
复用：L? 命中<来源> ｜ 缺口：<还缺什么>
路径：1) … 2) … 3) …（行数 = 实际动作数）
工具：<要用的工具 / 技能 / 命令>
产物：<交付形态 + 篇幅上限>
风险：<不可逆点、需用户确认点>
```

## 第 3 步 · 审视（必做，一轮为限）

拿策略卡回看原问题，逐条核对：

- [ ] **答对题**：解决的是用户真正问的那件事，不是我以为的那件？
- [ ] **还能更短**：少一步？少一次检索？少一个中间产物？
- [ ] **没跳级**：该查官方文档的没凭记忆作答？该复用的没重造？
- [ ] **没超纲**：产物是用户要的，不是「顺手多做」的？

任一不过 → 改策略卡，重走第 2 步。**只允许回炉一轮**；二轮仍不过 → 把分歧点一句话抛给用户，不硬做。

## 第 4 步 · 执行与交付

- 严格按策略卡执行；中途偏离就回填卡片，**不许悄悄改道**。
- 交付顺序：**结论先行** → 必要依据（表格优先于段落）→ 需要用户动手的下一步。
- 不写客套开场、不复述用户的话、不贴过程流水账、不附「顺便还可以…」。

## 沉淀（已解决才写）

四问全过才写，任一不过就不写：

1. **可复用**：下次遇到同类问题能直接用？
2. **是事实 / 动作**，不是过程描述？（「X 会导致 Y」✅ ｜「我先试 A 又试 B」❌）
3. **不重复**：既有记忆或技能里没有？（有 → 并入原条，不新开）
4. **低熵**：一句话说得清因果？（说不清就别记）

落位：

| 内容性质 | 落位 |
|---|---|
| 本次做了什么、结论、改动点 | 项目 `.workbuddy/memory/YYYY-MM-DD.md`（追加，不覆盖） |
| 项目级长期约定 / 红线 / 口径 | 项目 `.workbuddy/memory/MEMORY.md` |
| 跨项目偏好 / 习惯 | `~/.workbuddy/MEMORY.md` |
| 可复跑的多步流程 | **不写记忆——升级为 SKILL** |

**禁止写入**：临时路径与时间戳、工具报错原文、一次性检索结果、未验证的推测、情绪化结论、流水账。

**未解决** → 不写记忆，只回报阻塞点与下一步。

## 边界

- **与 `auto`（AUTO 总入口）**：`auto` 是「主题 → 步骤」的内容库（付费解锁，走 mcp.auto）；本技能是方法层，纯本地、零依赖，不检索内容库也不回写。
- **与「精卫」**：精卫是执行引擎（定位根因、多渠道找方案、落地执行）；本技能是提示协议（先策略、再审视、后沉淀、交付精简）。策略卡判定为排查类时，在「工具」一栏点名交给精卫，不重复造轮子。
- 本技能不替代领域技能，也不做内容生产，只约束「怎么想、怎么做、怎么收」。
