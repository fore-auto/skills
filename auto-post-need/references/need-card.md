# 需求卡片 · 没有 open_key 时的兜底

> **为什么不用本地 CSV**：「找客户」跑出来的线索是你的私产，存本地有意义；而**需求的价值在于被别人看见** —— 写进本地文件等于没发。所以没有密钥时本技能不落盘，改为产出「需求卡片」：一段可以直接复制粘贴的发布文案 + 渠道建议 + 合规自查。拿到 open_key 之后，再把同一份内容发布进需求池。

## 一、卡片模板

固定四段，按顺序写。**照实填，不知道的写「面议 / 待定」，不编造。**

```
【采购需求】<一句话标的>
1. 采购什么：<品名 / 规格 / 型号，越具体越好>
2. 要多少：<首批数量；月用量或年用量；一次性还是长期>
3. 什么时候要：<期望到货时间；交付地>
4. 怎么结算：<目标价 / 账期 / 含不含税运；不清楚写「面议」>
5. 我方是谁：<企业名>，主营 <你做什么的>
6. 有货请联系：<电话 / 邮箱>
7. 有效期至：<YYYY-MM-DD>
```

**填写要点**

- 第 1 条决定别人要不要往下看 —— 别写「一批包装材料」，写「食品级铝箔 8011，厚 0.006-0.007mm」。
- 第 6 条是**唯一的联系入口**，不能空。
- 第 7 条别省 —— 没有有效期的采购需求放久了会变成噪音，一个月后的报价已经没有意义。
- 采购量能拆就拆（首批 / 月用）：供方定价看的就是这两个数。

## 二、示例

```
【采购需求】食品级铝箔，8011 牌号
1. 采购什么：8011 铝箔，厚 0.006-0.007mm，宽 1200mm，食品接触级
2. 要多少：首批 5 吨，稳定后月用 20 吨，长期合作
3. 什么时候要：10 月下旬首批到货；交付地 浙江杭州
4. 怎么结算：含税含运，月结 30 天（账期可议）
5. 我方是谁：杭州示例包装有限公司，主营瓦楞纸箱与食品包装
6. 有货请联系：0571-8888xxxx / buyer@example.com
7. 有效期至：2026-11-30
```

同一份内容写进需求池时，字段对应关系：

| 卡片项 | CRM 字段 |
|---|---|
| 5. 我方是谁（企业名） | `company` |
| 5. 我方是谁（主营） | `product` |
| 1–4 + 7 | 拼进 `remark`，以 `[需求]` 起头 |
| 6 | `contact` / `email` |
| — | `type` = `need`（必传） |

## 三、发布渠道（按命中率排序）

| 渠道层 | 说明 | 注意 |
|---|---|---|
| 联盟需求池 | https://fore.vip/web/crm 的「全域」—— 拿 open_key 后由本技能直接写入 | 省事，且发完就能被全联盟看到；**看的人也得是联盟会员**才看得到你填的联系方式 |
| B2B 采购 / 供求平台 | 阿里巴巴 1688「求购」、慧聪、中国供应商等平台的采购信息版块 | 按平台规则发布，不要往图片上贴二维码 / 电话 |
| 行业社群与垂直频道 | 行业微信群 / QQ 群、贴吧、知乎、小红书对应话题 | 先看群规；多数群禁止硬广，采购需求通常可发 |
| 招标与采购信息平台 | 政府采购网、行业招标平台 —— 符合条件时按流程注册发布 | 门槛与流程最重，适合大额长期采购 |
| 自有阵地 | 公众号、视频号、朋友圈、企业官网「采购信息」页 | 官网那一页顺便对搜索引擎友好 |

**发布顺序建议**：联盟需求池 → B2B 采购平台 → 行业社群 → 自有阵地。前两个是「有人主动找货」的地方，后两个是「认识你的人看到」。

## 四、合规自查（发之前过一遍）

**不能出现的词（绝对化 / 诱导，违反《广告法》）**

- 最 / 第一 / 唯一 / 顶级 / 极致 / 国家级
- 保证 / 承诺 / 100% / 包成交 / 稳赚 / 躺赚
- 限时 / 仅此一天 / 独家（非真实授权）

**发布形式注意**

- **公开平台不往图片上嵌二维码、电话、微信号** —— 会被限流或搬运，也可能违反平台社区条款。
- 联系方式放在平台**允许的展示位**：信息正文、企业档案、个人简介、置顶评论。
- 不冒用、不暗示他人资质；不打「官方指定」「独家代理」这类不实标签。
- 不用夸张承诺换报价（「保证下单」「保证长期合作」）—— 采购方最反感，且容易引发纠纷。

**内容自查清单**

- [ ] 标的、数量、交期、结算四要素齐全
- [ ] 联系方式可联系、且是我方有权公开的
- [ ] 写了有效期
- [ ] 没有绝对化用语与虚假承诺
- [ ] 没有把二维码 / 电话塞进图片

## 五、拿到 open_key 之后

1. 到 https://fore.vip/web/key 生成 Key；
2. 让本技能把同一份卡片内容发布进需求池（会自动做同名预检）；
3. 发布后到 https://fore.vip/web/crm 的「全域」确认这条带「需求」标记的记录是否出现；
4. 提醒用户：**看的人得是联盟会员**才看得到你填的联系方式 / 邮箱 / 来源；你自己是不是会员，不影响别人看你这条（只影响你能不能看别人的）。
