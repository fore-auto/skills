# 口播结构模板与交付格式

## 一、时长 ↔ 字数对照

中文口播的舒适语速是 **240 字 / 分钟**，快节奏资讯腔到 **280 字 / 分钟**。取中位偏慢，因为电台风格本身比资讯腔慢。

| 时长 | 电台口播（240 字/分） | 偏快（280 字/分） |
|---|---|---|
| 3 分钟 | 720 | 840 |
| 5 分钟 | 1200 | 1400 |
| 8 分钟 | 1920 | 2240 |
| 10 分钟 | 2400 | 2800 |

**默认取 240 字/分那一列。** 用户给的字数与时长对不上时以时长为准，并在交付时说明取值。

## 二、五块结构 · 篇幅配比

以 5 分钟 / 1200 字为基准，其他时长按比例缩放：

| 块 | 时间 | 字数 | 占比 | 任务 |
|---|---|---|---|---|
| 钩子 | 0:00–0:25 | 120 | 10% | 抛一个具体细节、冲突或数字。不讲背景，不自我介绍 |
| 事实层 | 0:25–1:50 | 340 | 28% | 讲清发生了什么。2～3 个硬信息点 |
| 第二层 | 1:50–3:20 | 360 | 30% | 为什么 / 背后的账 / 反差。这一层决定稿子有没有价值 |
| 落点 | 3:20–4:30 | 280 | 23% | 按连接强度落到主题，或收在热点本身 |
| 收尾 | 4:30–5:00 | 100 | 9% | 一句记得住的话。不总结、不喊口号 |

## 三、三种连接强度 · 结构骨架

### 强连接（热点就是主题的语境 / 需求 / 痛点）

```
钩子（热点细节）
 → 事实层（热点讲透）
 → 第二层（大多数人只看懂一半）
 → 转场：把热点的需求平移到主题上，一句过渡，不铺垫
 → 主题占 50% 以上篇幅，给 2～3 个具体可执行点
 → 收尾（回扣钩子那个细节）
```

转场句要短，越短越不像广告。反例：「说到这里，我不得不提一下我们的产品」——这一句就毁了整条稿。

### 弱连接（只有关键词相近，逻辑牵强）

```
钩子（热点细节）
 → 事实层 + 第二层（把热点讲完，占 75% 以上）
 → 落点：只做一次邻接提及，一到两句，不下沉到产品
 → 收尾（收在热点上）
```

主题在这里只负责「露个脸」。**不要为它单开一段。**

### 无连接（不硬转）

```
钩子 → 事实层 → 第二层 → 收尾
```

全文纯热点稿，主题不提，或结尾一句自然带过。交付时**必须写明**「本次热点与主题无合理接口，已按纯热点稿处理」。这是合规做法，不是失败。

## 四、分段提示词模板（交付主体）

每段一块，字段固定，不要增删：

```
▍00:00–00:25 · 钩子 · 约 120 字 · 语速偏慢
【口播】<可直接念的完整文案，不出现任何标注符号>
【画面】<建议画面 / 字幕关键词>
【节奏】<停顿、重音、情绪>
```

字段含义：

| 字段 | 写法 |
|---|---|
| 时段 | `分:秒–分:秒`，与配比表对齐 |
| 段名 | 钩子 / 事实层 / 第二层 / 落点 / 收尾 |
| 字数 | 该段目标字数，允许 ±10% |
| 语速 | 偏慢 / 中速 / 偏快——钩子与收尾偏慢，事实层中速 |
| 【口播】 | 成稿正文。**这一段要能直接念**，不带括号说明、不带舞台提示 |
| 【画面】 | 画面建议 + 字幕关键词，三到五个词即可 |
| 【节奏】 | 哪里停、哪里重、情绪怎么走 |

交付时同时给 **E 连读版**：把所有【口播】按顺序拼成一段连续文本，无任何标注，可直接贴进 TTS 或提词器。

## 五、钩子句式库

前 15 秒决定完播。可用的开场方式：

1. **数字反差**——「官方公布的数字是 8.54 万个，但评论区里说得最多的，是排队四小时。」
2. **具体场景**——「晚上十一点，服务区的充电桩前面已经排到六十多号。」
3. **反常识**——「都以为今年不用排队了。真相比这个说法麻烦一点。」
4. **直接对谈**——「你最近是不是也刷到了这条？」
5. **时间锚点**——「今天早上这条上了热搜，我看到的时候排第七。」
6. **争议切入**——「两拨人在评论区吵起来了，而且都有道理。」
7. **数字提问**——「两个数字摆在一起，你就知道问题在哪了。」
8. **亲历感**——「这事我自己踩过，所以这次特意去查了。」
9. **限定范围**——「只说一种情况，就是最堵的那几条线。」
10. **悬念收窄**——「后面有条数据，是这件事里最少人提的。」

**禁用**：「不看后悔」「最后一条最关键」「看完你就懂了」「家人们谁懂啊」——这些是限流与掉粉双重风险。

## 六、AI 味 → 人话 对照

写完后逐条比对，右边才是目标。

| AI 味写法 | 人话写法 |
|---|---|
| 首先…其次…最后 | 直接说，用「其实」「话说回来」串联 |
| 在当今这个 XX 的时代 | 删掉，直接讲事 |
| 不仅…还… | 拆成两句短句 |
| 这无疑是一个值得深思的问题 | 说清是谁的问题、怎么解决 |
| 让我们一起看看 | 删掉，直接给信息 |
| 综上所述 / 总而言之 | 换成一句具体的话，或直接不写 |
| 赋能 / 闭环 / 抓手 | 用大白话重说 |
| 情绪稳定的排比三连 | 留一句最有力的，删掉另外两句 |
| 你觉得呢？ | 换成陈述式收尾 |
| 每段都一样长、一样节奏 | 长短交错，有的段落两句话就够 |

判据只有一条：**像一个真人对着镜头说话，不像一篇稿子被念出来。**
