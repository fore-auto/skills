# 合规预检 · 三张表

> 出稿后**先跑这张表，再去做去 AI 味**——改词会动字数，顺序反了要重算两遍。
> 本文件是自查工具，不构成法律意见；平台规则持续变化，**以平台最新规则为准**。

## 表一 · 违禁词（必须清零）

| 类别 | 典型词 | 处理 |
|---|---|---|
| 绝对化 | 最、第一、唯一、首个、顶级、极致、王牌、冠军、无敌、百分百、史上最强 | 删或改为具体事实（「最便宜」→「比上一代便宜 40 元」） |
| 承诺效果 | 保证、包过、稳赚、躺赚、零风险、立竿见影、一次见效、永不复发 | 删除承诺，改为条件式表述（「有人靠这个」→「这类做法适合有 X 条件的人」） |
| 无据权威 | 专家推荐、官方认证、国家专利（未给编号）、权威机构认定 | 有据就补来源，无据就删 |
| 医疗断言 | 治疗、治愈、根治、药用、疗效、抗炎、提高免疫力 | 一律删除，改为生活体验表述 |
| 金融荐股 | 荐股、稳赚、内幕、带你赚钱、收益率承诺、保本 | 一律删除，本技能不写此类选题 |
| 迷信 | 转运、化解、改命、风水布局 | 删除 |
| 低俗擦边 | 性暗示、身材羞辱、地域黑称 | 删除 |
| 涉政涉灾 | 政治评价、历史争议、遇难人数渲染、事故细节消费 | 整段删除，重写选题 |
| 未成年人 | 姓名、学校、照片、住址、可识别身份 | 一律脱敏 |

## 表二 · 平台限流词（按平台口径扫）

| 平台 | 最敏感的三类 | 注意 |
|---|---|---|
| 抖音 | 站外引流、绝对化 + 导流叠加、直接导购 | 绝对化和引流词同时出现，风险叠加，最容易踩 |
| 视频号 | 向公众号引流需明确关系、金融医疗内容需资质 | 对时长宽容，对资质严格 |
| 小红书 | 站外引流、功效宣称 | 对「体验分享」宽容，对「功效承诺」极严 |
| B站 | 商业推广未标注 | 有商业关系必须标「含商业推广」 |
| 快手 | 卖惨营销、砍价套路 | 情绪化卖惨类表述要降调 |
| 播客 / 电台 | 相对宽松 | 但内容仍需过表一 |

高频限流词：**加微信、私信我、评论区扣 1、主页领取、加群、私域、点击购买、下单、链接在橱窗、拉踩、diss 某品牌**。

处理原则：口播稿里**不做任何站外引流动作**。需要承接就在画面提示里写「主页」，不写「加微信」。

## 表三 · 营销降级词（不违规，但降低可信度）

用户的原话是「不要显得过于 AI 化」——这一类是主犯。

| 类型 | 词 |
|---|---|
| 互联网黑话 | 赋能、闭环、抓手、颗粒度、对齐、心智、方法论、打法、组合拳、面向未来 |
| 标题党 | 震惊、不看后悔、必看、绝了、YYDS、封神、破防 |
| 直播腔 | 家人们、宝子们、老铁们（播客与视频号不宜，抖音可极少量） |
| 空转承接 | 那么问题来了、接下来让我们、值得注意的是、由此可见 |

处理原则：黑话直接删，标题党换成具体信息，直播腔按平台调性删或降频。

## 处理流程（固定四步）

1. **扫**：通读全文，按三张表逐条比对，标出全部命中项。
2. **分类**：判定是「必须删」（表一）还是「可以换」（表二表三）。
3. **三种改法选一**：
   - **删**——删掉不影响语义时首选，最短最安全；
   - **换**——换同义自然口语（「赋能」→「帮上忙」）；
   - **改**——整句重组（绝对化断言改为有条件的陈述）。
4. **复核**：改完重新数字数，确认仍在目标区间；确认**事实、数字、专有名词没有被改动**。

输出格式固定三列：**原词 → 替换 → 位置（段落 / 时间点）**。

## 自检清单（改完念一遍）

1. 有没有一句话可以被理解为「保证结果」？
2. 有没有出现「最」字打头的断言？
3. 有没有明确的引流动作？
4. 有没有把别人的苦难当素材？
5. 有没有互联网黑话一句没删干净？
6. 事实和数字，与信源对得上吗？

## 红线

- **不许为了过检改事实。** 改的是表达，不是内容。
- **不许承诺「绝对安全」。** 本表是常见项集合，不等于平台审核的真实清单。
- **不许在灾难、伤亡、未成年人、医疗、荐股类选题上找擦边写法。** 这类选题直接不做，不改写。
